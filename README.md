# TAC social media assets

Public images for The Anchored Compass social posts, linked by Buffer drafts.
Buffer needs a public, direct link to each image; this repo provides those links.

- `week1/` — Week 1 (Oct 19 to Oct 25, 2026) images for Instagram (also used for the Facebook Page) and X.
- `week2/` — Week 2 (Oct 26 to Nov 1, 2026) images for Instagram, the Facebook Page and X.
- `week2-video/` — Week 2 TikTok and YouTube Shorts videos, with their music license record.

Only approved, already-public post graphics belong here. No personal data, keys or drafts.
